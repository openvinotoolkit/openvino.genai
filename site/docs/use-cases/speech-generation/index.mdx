# Speech Generation

:::info Note
Speech generation supports multiple model families, including SpeechT5, Kokoro, and Qwen3-TTS.
The generated audio signal is a single-channel (mono) waveform, and the sampling rate depends on the model
(for example, SpeechT5 outputs 16 kHz and Qwen3-TTS outputs 24 kHz).
:::

<ConvertModelSection>
    Download and convert model (for example, [speecht5_tts](https://huggingface.co/microsoft/speecht5_tts)) to OpenVINO format from Hugging Face.
    The command below uses SpeechT5 as an example; SpeechT5 requires specifying a vocoder via `--model-kwargs`:

    <OptimumCLI model='microsoft/speecht5_tts' outputDir='speecht5_tts' weightFormat='int4' modelKwargs={{
        vocoder: "microsoft/speecht5_hifigan"
    }} />

    See all supported [Speech Generation Models](/docs/supported-models/#speech-generation-models).
</ConvertModelSection>
