# Convert Models to OpenVINO Format

This page explains how to convert various generative AI models from [Hugging Face](https://huggingface.co/) and [ModelScope](https://modelscope.cn/) to OpenVINO IR format.
Refer to the [Supported Models](../../supported-models/index.mdx) for a list of available models.

For downloading pre-converted models, see [Download Pre-Converted OpenVINO Models](./download-openvino-models.mdx).

## Converting Models from Hugging Face

1. Install `optimum-intel` package to download, convert and optimize models:

    :::info Note
    Some models may require additional dependencies.
    To convert models with `optimum-cli` and to run the examples, install the dependencies from [`./samples/export-requirements.txt`](https://github.com/openvinotoolkit/openvino.genai/blob/master/samples/export-requirements.txt).
    :::

    ```bash
    pip install --requirement ./samples/export-requirements.txt
    ```

2. Download and convert a model to the OpenVINO IR format using `optimum-cli` tool from Hugging Face:
    <OptimumCLI />

    :::tip

    For better performance with minimal accuracy impact, convert the model to lower precision by using `--weight-format` argument:

    <Tabs groupId="export-precision">
        <TabItem label="INT4" value="int4">
            <OptimumCLI weightFormat='int4' />
        </TabItem>
        <TabItem label="INT8" value="int8">
            <OptimumCLI weightFormat='int8' />
        </TabItem>
        <TabItem label="FP16" value="fp16">
            <OptimumCLI weightFormat='fp16' />
        </TabItem>
    </Tabs>

    :::

    :::info

    The `--trust-remote-code` flag is required for some models that use custom code.

    Check a full list of conversion options [here](https://huggingface.co/docs/optimum/en/intel/openvino/export).

    :::

## Converting Models with genai-cli {#genai-cli}

OpenVINO GenAI ships its own export tool, `genai-cli`, with the same options as `optimum-cli export openvino`.
The models in the table below are converted natively by `genai-cli` and do not need `optimum-intel` at all;
every other model is exported through `optimum-intel` with the same command line.

1. Install OpenVINO GenAI with the export dependencies (`torch`, `torchvision`, `transformers`, `nncf` and `uv`):
    ```bash
    pip install openvino-genai[export]
    ```

2. Export a model. For example, Molmo2 (`allenai/MolmoWeb-4B`) compressed to INT4:
    ```bash
    genai-cli export -m allenai/MolmoWeb-4B --trust-remote-code --weight-format int4 MolmoWeb-4B-ov-int4
    ```
    The output directory contains the OpenVINO IRs, the converted tokenizer and detokenizer, and the configuration
    files the GenAI pipelines read, so it can be passed to `VLMPipeline` directly.

| Model type | Architecture | Converted by | transformers version |
|------------|--------------|--------------|----------------------|
| `molmo2` | `Molmo2ForConditionalGeneration` | `genai-cli` (native) | 4.57.6 |
| Any other | | `optimum-intel` | Supported by `optimum-intel` for the model |

:::info How genai-cli provides dependencies

- **transformers version.** Every model is exported with the `transformers` version it is known to work with.
  If the installed version differs, `genai-cli` runs the export again in an ephemeral environment created by
  [`uv`](https://docs.astral.sh/uv/) on top of the active one (`uv run --with transformers==<version>`).
  The active virtual environment is never modified; the overlays are cached by `uv`.
- **Fallback exports.** For models without a native exporter, `genai-cli` runs `optimum-cli export openvino` with
  the same arguments. If `optimum-intel` is not installed, it is downloaded (without dependencies) to
  `~/.cache/openvino_genai/genai-cli`, and `torch`, `openvino` and `nncf` are taken from the active environment.
  Set `GENAI_CLI_OPTIMUM_INTEL_SPEC` to export with another `optimum-intel` version, for example
  `optimum-intel @ git+https://github.com/huggingface/optimum-intel.git`.
- **Native exporters** support FP32, FP16 and data-free weight compression (`int8`, `int4`, `mxfp4`, `nf4`, `cb4`,
  with `--ratio`, `--group-size`, `--sym`, `--awq` and the other data-free options). Data-aware compression
  (`--dataset`), full quantization (`--quant-mode`), `--disable-stateful` and `--model-kwargs` are rejected for them.

:::

## Converting Models from ModelScope

ModelScope models need to be downloaded first, then converted to OpenVINO IR format.

1. Install `modelscope` and `optimum-intel` packages to download, convert and optimize models:
    ```bash
    pip install modelscope --requirement ./samples/export-requirements.txt
    ```
2. Download the required model (e.g. `Qwen/Qwen2-7b`) to a local directory using `modelscope` tool:
    ```bash
    modelscope download --model 'Qwen/Qwen2-7b' --local_dir <model_path>
    ```
3. Convert the model (and optionally compress weights) using `optimum-cli` tool:
    <OptimumCLI model='<model_path>' weightFormat='int4' />
